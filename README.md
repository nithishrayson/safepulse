# SafePulse (Mangai)

**SafePulse** is a real-time women safety mobile application built with **Flutter**. It enables emergency communication and location tracking to ensure fast response during distress situations. This project, also referred to as **Mangai**, focuses on empowering safety through smart, reliable technology.

---

## 🚨 Features

- Real-time location tracking  
- One-tap SOS alert system with backend integration  
- Secure user authentication  
- Interactive and responsive user interface  
- Firebase for real-time database and user management  
- Node.js backend for handling SOS requests securely

---

## 🛠 Tech Stack

- **Frontend:** Flutter, Dart  
- **Backend:** Node.js, Express.js  
- **Database:** Firebase Realtime Database  
- **Location Services:** Google Maps API  
- **DevOps:** Git, Docker (optional)  
- **Cloud Services:** Firebase, basic AWS knowledge (for deployment-ready architecture)

---

## 📦 Getting Started

### Prerequisites

- Flutter SDK installed  
- Android Studio or VS Code  
- Firebase project setup  
- Node.js installed

### Installation

```bash
git clone https://github.com/nithishrayson/mangai.git
cd mangai
flutter pub get
flutter run

```

### Backend Setup
```bash
cd backend
npm install
node index.js
